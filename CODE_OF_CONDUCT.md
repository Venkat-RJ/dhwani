# Code of conduct

Everyone should be able to contribute without harassment.
Treat people respectfully regardless of identity, background, experience, or ability.
Critique the work with specific evidence and give others room to correct mistakes.

Harassment, threats, sexualized comments, personal attacks, and publishing another person's private information are unacceptable.
Keep discussion relevant to the project and respect requests to stop unwanted contact.

These expectations apply to issues, pull requests, reviews, and other project spaces.
Maintainers may remove content, restrict participation, or ban repeated or serious misconduct.
Moderation should reflect the behavior and its impact.

Use GitHub's **Report content** controls to report inappropriate public content.
The maintainer is [Venkat-RJ](https://github.com/Venkat-RJ).
Use any private contact details the maintainer publishes for sensitive information.
Do not include personal details in a public issue or use the vulnerability-report channel for unrelated conduct reports.
