# Dhwani icon

The selected design shows a person speaking, three sound waves, and a computer screen with text and an insertion cursor.

The artwork was generated with the built-in image generation tool on 7 October 2026.
The original selected image is preserved in `assets/brand/dhwani-person-wave-screen.png` at 1254 by 1254 pixels.
`assets/icon.png` is the 1024 by 1024 master used by the README and website.
The macOS asset catalog contains resized copies at the dimensions in its `Contents.json`.
These copies were packaged with macOS `sips` without changing the selected composition.
The website header uses `assets/logo-80.png` at 40 CSS pixels.
Its favicon files are `assets/favicon-16.png` and `assets/favicon-32.png`, so the browser can use their native small sizes.

The selected image has an opaque background.

## Generation prompt

```text
Use case: logo-brand.
Asset type: preview concept for the macOS voice dictation app Dhwani, a square app icon.
Primary request: a person speaking, their voice moving as sound waves toward a computer on the other side. Make the journey from human speech to computer writing immediately understandable.
Composition: a simplified gender-neutral human head in profile on the left, facing right. Three bold curved sound-wave arcs emerge from the mouth in the middle. A compact desktop computer screen on the right receives the waves. Inside the screen, only two short horizontal text strokes and one insertion cursor, no actual letters.
Style: refined flat geometric icon, vector-like edges, bold silhouettes, generous negative space, consistent geometry. All three parts have enough visual weight to survive at 32px. Distinctive and calm, without stock clip-art styling.
Palette: bright lime green #beff78 on deep charcoal green #101610, matching Dhwani's existing app and website. A dark rounded square app tile centered on a slightly darker square canvas.
Constraints: no words, no labels, no letters, no watermark. No microphone, headphones, clouds, robots, arrows, gradients, glow, tiny facial details, thin outer border or photorealism. This is a concept for discussion, not a website screenshot.
```
